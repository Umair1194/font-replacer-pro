A considered font swap.

  1. Choose a scope and scan its text layers.
  2. Pick a destination for each source font, or map a whole family with matching styles.
  3. Review the changes, then replace.

Only fonts available in Figma can be selected. Family mapping uses exact or spacing-normalized style names; unresolved styles stay unmapped.

Text content and other formatting are preserved. Font metrics can change wrapping and layout. Font changes can create text-style overrides. Variable source axes reset to the selected destination’s named style.

Cancel stops future changes; completed changes remain. Use Figma’s native Undo to revert. Undo grouping and missing-font recovery still need validation in your Figma editor.
